# GAS-Mondai（問題集）

Google Apps Script（GAS）+ Googleスプレッドシートで動作する、昇任試験対策用の問題集Webアプリです。

スプレッドシートを問題データベースとして使い、出題・検索・正答率の統計管理・ブックマークができます。

## 主な機能

### 出題（トップページ）

- シート単位・ジャンル単位で出題範囲を絞り込み
- 出題モードの切り替え
  - 通常出題（ランダム）
  - ブックマークした問題のみ
  - 苦手問題（2回以上不正解の問題）
  - 未出題の問題のみ
  - 正答率60%以下の問題
- 回答後に正解・解説・根拠条文を表示
- 解答結果は自動で履歴シートに記録
- 気になった問題をその場でブックマーク

### 検索

- キーワードで全シート横断検索（問題文・解説が対象）
- アコーディオン形式で正解・解説を表示

### 学習統計

- シート別の正答率一覧（トップページ）
- ジャンル別正答率のグラフ表示（Chart.js）
- 誤答率の高い「苦手問題」TOP3をランダム表示

### ブックマーク

- ブックマークした問題の一覧表示・削除
- ユーザーごとに個別管理（`Session.getActiveUser().getEmail()`で識別）

## ファイル構成

```
GAS-Mondai/
├── Code.gs          サーバーサイドロジック（データ取得・検索・履歴・統計）
├── appsscript.json   GASプロジェクトのマニフェスト
├── Style.html        共通CSS（ダークモード基調のデザイントークン）
├── Header.html       共通ヘッダー・ナビゲーション
├── index.html        出題ページ（トップ）
├── search.html       検索ページ
├── stats.html        学習統計ページ
└── bookmarks.html    ブックマーク一覧ページ
```

`Style.html`と`Header.html`は`Code.gs`内の`include()`関数を通じて各ページに読み込まれる共通パーツです。ページ間でヘッダーやデザインが重複しないようにしています。

## スプレッドシートの構成

問題データは以下の6列構成のシートとして用意します（1行目はヘッダー行）。

| 列 | 内容 |
| --- | --- |
| A | （未使用／空でも可） |
| B | ジャンル |
| C | 問題文 |
| D | 正誤（○ または ×） |
| E | 解説 |
| F | 根拠条文 |

シート名がそのまま出題範囲の選択肢（「地方自治法」「地方公務員法」など）になります。

以下のシート名は特殊シートとして扱われ、出題対象シートの一覧からは除外されます。

- `履歴` — 解答履歴が自動記録されるシート（存在しなければ自動作成）
- `ブックマーク` — ブックマーク情報が自動記録されるシート（存在しなければ自動作成）

## セットアップ手順

1. Googleスプレッドシートを新規作成し、問題データを上記の列構成でシートに用意する
2. スプレッドシートのメニューから「拡張機能」→「Apps Script」を開く
3. 本リポジトリの各ファイルをGASエディタ上に同名で作成・貼り付ける
   - `Code.gs`（既存のCode.gsを置き換え）
   - `Style.html`（新規HTMLファイル）
   - `Header.html`（新規HTMLファイル）
   - `index.html` / `search.html` / `stats.html` / `bookmarks.html`
4. `appsscript.json`の内容を反映する（GASエディタの「プロジェクトの設定」から表示可能）
5. 「デプロイ」→「新しいデプロイ」からWebアプリとして公開する
   - 実行するユーザー：自分／アクセスできるユーザーを利用目的に応じて設定
6. 発行されたURLにアクセスして動作確認する

コードを更新した場合は、既存のデプロイを編集して「新しいバージョン」として再デプロイする必要があります（URLは変わりません）。
